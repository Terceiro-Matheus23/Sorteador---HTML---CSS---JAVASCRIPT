# Sorteador---HTML---CSS---JAVASCRIPT
sorteador de números feito pelo html, css e javascript
Aplicação web desenvolvida para realizar o sorteio de números dentro de um intervalo definido pelo usuário.

🛠️ Tecnologias
HTML5
CSS3
JavaScript

📌 Sobre o projeto

O projeto consiste em uma página web na qual o usuário informa um intervalo de números e, ao acionar o botão de sorteio, a aplicação gera um número aleatório dentro do intervalo informado.

🎯 Funcionalidades
Definição do número inicial
Definição do número final
Geração de número aleatório
Interação por meio de botão
Interface estilizada com CSS

📚 Conhecimentos praticados
Estruturação de páginas com HTML
Estilização e centralização de elementos com CSS
JavaScript
Lógica para geração de números aleatórios
Interação entre elementos da página e JavaScript

🚀 Como executar
Clone este repositório.
Abra o arquivo index.html no navegador.
Informe o número inicial e o número final.
Clique no botão para realizar o sorteio.
